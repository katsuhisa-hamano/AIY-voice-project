# AIY-voice-project

Google AIY Voice Kit と Google Assistant SDK を利用した個人用の音声アシスタントプロジェクトです。

## Privacy Policy

This project is for personal, non-commercial use only. It uses the Google Assistant SDK to send audio queries to Google Assistant and receive responses. No audio or personal data collected by this application is stored, shared, or used for any purpose other than operating the assistant on the owner's own device. No data is shared with third parties.

本プロジェクトは個人的な非商用利用のみを目的としています。Google Assistant SDKを使用して音声クエリをGoogle Assistantに送信し、応答を受け取ります。本アプリケーションが収集する音声データや個人データは、所有者自身のデバイス上でアシスタントを動作させる目的以外には保存、共有、使用されません。第三者へのデータ提供は行いません。
